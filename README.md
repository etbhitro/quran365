# Коран за 365 дней — Telegram-бот (MVP)

Бот делит весь Коран (6236 аятов) на 365 частей по дням. Каждый день он
показывает отрывок на арабском с переводом. Выучил(а) — отмечаешь командой
`/done`, бот засчитывает день и предлагает следующий. Прогресс сохраняется.

## Что умеет MVP

- 📅 План на 365 дней (число дней настраивается).
- 🧩 Деление по аятам (~17/день) с учётом границ сур: короткие суры не
  разрываются между днями.
- 📖 Показ аятов дня: арабский текст + перевод.
- ✅ Отметка «выучил» (`/done`) с переходом к следующему дню.
- 📊 Прогресс (SQLite): текущий день и сколько пройдено.

### Про аудио-проверку (следующий этап)

Проверка чтения по голосовому — в планах, но не в этой версии. Код сравнения
текста уже лежит в `bot/checker.py` и готов к подключению: он распознаёт, какие
*слова* прочитаны (Whisper), и сравнивает со словами аята без огласовок — то есть
ловит пропущенные/лишние/перепутанные слова. Это не проверка таджвида (махрадж,
протяжённости) — для неё нужны специализированные модели. Как включить — см.
«Куда развивать».

## Нужен ли Python?

Да. Проект на Python (подойдёт версия 3.10+). Больше ничего устанавливать не
нужно — база прогресса на встроенном SQLite, внешних ключей для MVP не требуется.

## Установка

```bash
# 1. Клонировать и зайти в папку
cd quran365

# 2. Виртуальное окружение (рекомендуется)
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Настройки
cp .env.example .env
# открой .env и впиши TELEGRAM_BOT_TOKEN
```

### Где взять токен

- **TELEGRAM_BOT_TOKEN** — напиши [@BotFather](https://t.me/BotFather) в Telegram,
  команда `/newbot`, он выдаст токен. Это всё, что нужно для MVP.

## Запуск

```bash
# 1. Один раз: скачать текст Корана и построить план (нужен интернет)
python scripts/build_plan.py

# 2. Запустить бота
python -m bot.main
```

Теперь напиши своему боту в Telegram `/start`.

## Команды бота

| Команда      | Что делает                                  |
|--------------|---------------------------------------------|
| `/start`     | Приветствие и аяты текущего дня             |
| `/today`     | Показать задание на сегодня                 |
| `/next`      | Перейти к следующему дню                    |
| `/day N`     | Перейти к дню № N                           |
| `/done`      | Отметить текущий день выученным и идти дальше |
| `/progress`  | Прогресс по дням                            |

## Структура проекта

```
quran365/
├── bot/
│   ├── main.py       # запуск бота и обработчики команд/аудио
│   ├── config.py     # чтение настроек из .env
│   ├── plan.py       # загрузка плана и текста Корана
│   ├── progress.py   # прогресс пользователей (SQLite)
│   └── checker.py    # распознавание речи + сравнение с аятом
├── scripts/
│   └── build_plan.py # скачивает Коран и строит план на 365 дней
├── data/             # сюда кладутся сгенерированные quran.json, plan.json, progress.db
├── requirements.txt
└── .env.example
```

## Источник текста

Текст Корана и перевод берутся из бесплатного API
[alquran.cloud](https://alquran.cloud/api) (арабский `quran-uthmani`, перевод
по умолчанию — Э. Кулиев `ru.kuliev`). Перевод меняется переменной
`TRANSLATION_EDITION` в `.env`.

## Куда развивать (следующие шаги)

- **Аудио-проверка чтения.** Логика уже есть в `bot/checker.py`. Чтобы включить:
  1. раскомментируй `openai` в `requirements.txt` и установи;
  2. впиши `OPENAI_API_KEY` в `.env`;
  3. в `bot/main.py` замени обработчик `on_voice` на вызов
     `checker.check_recitation(...)` (прежний вариант сохранён в истории git).
- Напоминания по расписанию (одно задание в день).
- Режимы: заучивание наизусть (текст скрыт), повторение пройденного.
- Стрик — сколько дней подряд, и таблица лидеров.
