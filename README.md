# Коран за 365 дней — Telegram-бот (MVP)

Бот делит весь Коран (6236 аятов) на ~равные части по дням. Каждый день он
присылает отрывок на арабском с переводом. Ты читаешь его вслух и отправляешь
**голосовое сообщение** — бот распознаёт речь и показывает, где есть расхождения
с текстом, а также считает процент совпадения.

## Что умеет MVP

- 📅 План на 365 дней (число дней настраивается).
- 📖 Команда показывает аяты дня: арабский текст + перевод.
- 🎤 Приём голосового → распознавание (Whisper) → пословный разбор ошибок.
- 📊 Отслеживание прогресса (SQLite): текущий день и пройденные дни.

### Честно о проверке аудио

Это **MVP**, а не проверка таджвида. Бот распознаёт, *какие слова* ты прочитал,
и сравнивает со словами аята **без огласовок**. Так ловятся грубые ошибки:
пропущенные, лишние и перепутанные слова. Тонкости произношения (махрадж,
протяжённость, правила таджвида) так проверить нельзя — для этого нужны
специализированные модели. Это осознанный компромисс ради быстрого запуска.
Дальше точность проверки можно наращивать (см. «Куда развивать»).

## Нужен ли Python?

Да. Проект на Python (уже подойдёт версия 3.10+). Больше ничего
устанавливать не обязательно — база прогресса на встроенном SQLite.

## Установка

```bash
# 1. Клонировать и зайти в папку
cd quran365

# 2. Виртуальное окружение (рекомендуется)
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate

# 3. Зависимости
pip install -r requirements.txt

# 4. Настройки
cp .env.example .env
# открой .env и впиши TELEGRAM_BOT_TOKEN и (для аудио) OPENAI_API_KEY
```

### Где взять токены

- **TELEGRAM_BOT_TOKEN** — напиши [@BotFather](https://t.me/BotFather) в Telegram,
  команда `/newbot`, он выдаст токен.
- **OPENAI_API_KEY** — на https://platform.openai.com/api-keys (нужен для
  распознавания аудио). Без него бот работает, но аудио проверять не сможет.

## Запуск

```bash
# 1. Один раз: скачать текст Корана и построить план (нужен интернет)
python scripts/build_plan.py

# 2. Запустить бота
python -m bot.main
```

Теперь напиши своему боту в Telegram `/start`.

## Команды бота

| Команда      | Что делает                                  |
|--------------|---------------------------------------------|
| `/start`     | Приветствие и аяты текущего дня             |
| `/today`     | Показать задание на сегодня                 |
| `/next`      | Перейти к следующему дню                    |
| `/day N`     | Перейти к дню № N                           |
| `/progress`  | Прогресс по дням                            |
| 🎤 голосовое | Проверить чтение текущего дня               |

## Структура проекта

```
quran365/
├── bot/
│   ├── main.py       # запуск бота и обработчики команд/аудио
│   ├── config.py     # чтение настроек из .env
│   ├── plan.py       # загрузка плана и текста Корана
│   ├── progress.py   # прогресс пользователей (SQLite)
│   └── checker.py    # распознавание речи + сравнение с аятом
├── scripts/
│   └── build_plan.py # скачивает Коран и строит план на 365 дней
├── data/             # сюда кладутся сгенерированные quran.json, plan.json, progress.db
├── requirements.txt
└── .env.example
```

## Источник текста

Текст Корана и перевод берутся из бесплатного API
[alquran.cloud](https://alquran.cloud/api) (арабский `quran-uthmani`, перевод
по умолчанию — Э. Кулиев `ru.kuliev`). Перевод меняется переменной
`TRANSLATION_EDITION` в `.env`.
